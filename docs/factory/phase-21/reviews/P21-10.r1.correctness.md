  location: src/test/e2e/specs/journey.spec.ts:22
  claim: The upload fixture path `'fixtures/biology.md'` is resolved against the process working directory, not the spec or config directory, so the spec only finds the file when Playwright is started from `src/test/e2e/`.
  evidence: Playwright `setInputFiles` resolves a relative path with `path.resolve(process.cwd(), ...)`. If you run `npx playwright test -c src/test/e2e/playwright.config.ts` from the repository root, the cwd is the root, `./fixtures/biology.md` does not exist there, and the step fails with ENOENT. The documented `npm test` in `src/test/e2e/` works, so this affects only other ways to start the run.
  fix: Resolve the path from the config root, e.g. `path.join(test.info().project.testDir, '..', 'fixtures', 'biology.md')`, or keep the current path and record in a comment that the suite must run from `src/test/e2e/`.
