- id: C1
  severity: major
  confidence: 0.7
  location: src/test/java/dev/mindforge/unit/architecture/MarkdownRegexGuardTest.java:37
  claim: The link check requires an escaped closing bracket (`\\]\\(`), so the common Java form of a markdown link regex with a bare `]` followed by an escaped paren is not reported.
  evidence: In Java regex a `]` outside a character class needs no escape, so `Pattern.compile("\\[(.+?)]\\((.+?)\\)")` is a valid and common inline-link regex. I copied the scanner logic (hasMarkdownRegex/literalsOfCall/isMarkdown) into a standalone run and planted `class X { Object p = Pattern.compile("\\[(.+?)]\\((.+?)\\)"); }` in a temp `src/main/java/X.java`. filesWithHits returned `[]`. The guard therefore misses an obvious T26 offender. D12 forbids flagging a raw `](`, which is `Identifier.PATTERN`'s `](?:`. It does not require the bracket to be escaped. A bracket followed by an *escaped* paren never occurs in Identifier, ArticleFetcher (`\\]\"`) or DocxParser.
  fix: Change ESCAPED_LINK to match `]\\(` as written in source (Java string `"]\\\\("`). This covers both `\\]\\(` and `]\\(` and still spares `](?:`. Add the bare-bracket shape to the AC3 planted offenders. On the real tree, hits stay MarkdownStructure and BundleConformanceValidator (INDEX_ENTRY contains `\\]\\(`).
- id: C2
  severity: minor
  confidence: 0.6
  location: src/test/java/dev/mindforge/unit/architecture/MarkdownRegexGuardTest.java:35
  claim: The heading check misses common ATX heading regexes in which only whitespace or a group comes before the `#` and no `## ` or `#{` follows, for example `"(?m)^\\s*#+ (.*)$"` or `"(^|\\n)# "`.
  evidence: The same standalone run reported `[]` for both planted literals. LEADING_HEADING allows only `(?flags)`, `^` and `(` in that order before `#`. `\\s*`, ` {0,3}` (CommonMark indentation, as in MarkdownStructure FENCE_OPEN) and `(^|\\n)` all skip it.
  fix: Before the `#`, allow optional leading whitespace or indentation tokens (`\\s*`, ` {0,3}`, ` *`) and an alternation group like `(^|\\n)`. As an alternative, flag `#+ ` / `# ` that follows `^` or `\\n` anywhere in the joined literal. Add one planted case.
