## Reasoning
- ci.yml already triggers on bare `push:` and `pull_request:` with no filters; A adds one job and no trigger logic.
- tech-stack.md CI/CD says build + test on every PR including Playwright E2E; A satisfies this literally.
- Factory gate stays green because the E2E is outside Maven verify (constraint met).
- B adds branch filters that nothing else in ci.yml uses, a new concept to save only runner minutes; it can be added later by editing one line.
- C puts browser and Docker image work into Maven, which is the slowest and most fragile place, and needs profile wiring.
- needs: linux avoids spending E2E minutes on a red build.
