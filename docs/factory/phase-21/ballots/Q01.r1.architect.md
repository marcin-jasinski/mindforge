## Reasoning
Measured on the tree (all src/**/*.java): 0 files with tabs, 0 with trailing whitespace, 0 missing final newline, 0 star imports,
0 loggers not named `log`, 0 `@Autowired` in src/main. So A's rules already pass, except two facts the question missed:
(1) 125 lines exceed 120 (46 in main, 79 in test; only 13 exceed 140) - a small, mechanical fix, so keep 120 with an
ignorePattern for import/package/URL lines; (2) 17 test files use field `@Autowired` in Spring integration tests, which is
the idiomatic test pattern and is not what CLAUDE.md forbids (the rule sits under "API / Controllers" and concerns beans).
So the @Autowired check must run on main sources only (checkstyle `<sourceDirectories>` or a suppression scoped to
src/test for that one check) - this is variant A'. Every rule then traces to an existing standard (.editorconfig: lf,
final newline, trim whitespace, indent 4; coding-style.md "No Dead Code ... unused imports"; CLAUDE.md logger `log`,
constructor injection), which is what a maintainer will still agree with in a year: the ruleset documents our standards,
not someone else's. B imports Google style the code does not follow and needs a baseline that hides debt; C does not
enforce anything. D (Spotless) rewrites files and does not check `log`/`@Autowired`; tech-stack.md lists "Checkstyle /
Spotless" and plan 21.1 names Checkstyle, so Checkstyle alone satisfies it.
## What would change my mind
Running Checkstyle UnusedImports shows hundreds of findings, or the owner wants a general-purpose stock style adopted now.
## Implementation notes
- `config/checkstyle/checkstyle.xml` (Checker: NewlineAtEndOfFile lineSeparator=lf, FileTabCharacter, RegexpSingleline
  `\s+$` trailing whitespace, LineLength max=120 ignorePattern `^(package|import) |https?://`; TreeWalker: AvoidStarImport,
  UnusedImports, RedundantImport, a Regexp/MatchXpath check for `@Autowired` on field defs, and a RegexpSinglelineJava or
  MatchXpath check that a `Logger` field from LoggerFactory is named `log`).
- `config/checkstyle/suppressions.xml`: suppress only the @Autowired-field check for `[/\\]src[/\\]test[/\\]`.
- pom.xml: `maven-checkstyle-plugin` (pinned version + pinned `com.puppycrawl.tools:checkstyle` dependency), execution
  `validate` phase goal `check`, `consoleOutput` true, `failOnViolation` true, `violationSeverity` warning,
  `includeTestSourceDirectory` true. Document the plugin in docs/project/tech-stack.md (Minimal Dependencies).
- Wrap the 125 over-length lines; CI step `mvn -B checkstyle:check` before SpotBugs.
