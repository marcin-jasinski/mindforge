## Reasoning
Measured on the tree (528 .java files): 0 tabs, 0 trailing-whitespace lines, 0 CRLF, 0 missing final newline, 0 star imports.
So most A rules pass today and the ruleset is real enforcement with near-zero churn. Two A rules break if written naively:
1. Line length 120 is NOT already met: 125 lines exceed 120 (46 in src/main, 79 in tests; 78 of the 125 hold a string literal).
   Mechanical wraps, low risk, but "fix the few findings" is ~125 edits, not "few". 2461 lines exceed 100, so do not go lower.
2. Field `@Autowired` exists in 17 test files (e.g. ConcurrentUploadTest.java:42, ApiFlowTest.java:69) -- the Spring Test
   idiom in @SpringBootTest; src/main has zero. The check must apply to src/main only, or the build fails on day one.
3. "Logger named log": src/main has no deviation, but tests capture loggers as `interceptorLog`, `fetcherLog`, a local
   `logger` (DiscordCommandHandlerTest.java:123). Match only `private static final Logger <name>` with name != log.
B fails how: suppressions keyed by file hide new violations in the same files; Google checks drag in Javadoc/naming/
indent rules the standards never stated (minimal-implementation.md: no speculative configuration); a large, opaque
diff of overrides nobody reviews. C fails silently: nobody reads a report that never fails; drift resumes at once.
Toolchain risk for every option: maven-checkstyle-plugin 3.x bundles an old Checkstyle (9.x) that cannot parse Java 21
records/sealed/pattern switch -- pin `com.puppycrawl.tools:checkstyle` 10.x+ as a plugin dependency, else parse errors.
How we find out it works: the gate (`mvn -B verify`) runs `check` in `validate`; prove it with one deliberate violation locally.

## What would change my mind
Evidence that wrapping the 125 long lines collides with other phase-21 work (merge churn) -> pick D or A' and add LineLength later.

## Implementation notes
- `config/checkstyle.xml` (Checker): `NewlineAtEndOfFile` (lineSeparator=lf), `FileTabCharacter`, `RegexpSingleline` `\s+$`
  (trailing whitespace), `LineLength` max=120 with ignorePattern `^(package|import) .*`; TreeWalker: `AvoidStarImport`,
  `UnusedImports`, `RedundantImport`, `RegexpSinglelineJava` format `static\s+final\s+Logger\s+(?!log\b)\w+` message "logger must be named log".
- Field @Autowired: `RegexpMultiline` or `AnnotationLocation`-free regex `@Autowired\s*\n\s*(private|protected|public)?\s*[\w<>,? ]+\s+\w+\s*;`
  with a `config/checkstyle-suppressions.xml` entry `<suppress checks="AutowiredField" files="[\\/]src[\\/]test[\\/]"/>` (use `id="AutowiredField"`).
- pom.xml: `maven-checkstyle-plugin` (3.6.x) with dependency `com.puppycrawl.tools:checkstyle` 10.2x+, `configLocation=config/checkstyle.xml`,
  `suppressionsLocation`, `includeTestSourceDirectory=true`, `consoleOutput=true`, `failOnViolation=true`, `violationSeverity=warning`,
  execution `id=checkstyle`, phase `validate`, goal `check`. Document the plugin in tech-stack.md § Linting (Minimal Dependencies).
- Fix the 125 >120 lines (list: `awk 'length>120{print FILENAME": "FNR}'`), no other code edits needed.
