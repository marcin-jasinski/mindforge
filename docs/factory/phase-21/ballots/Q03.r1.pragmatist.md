| C  | A plus split CI steps | 5 | 3 | 3 | 4 | 5 |
## Reasoning
CI has one `mvn -B verify` step (.github/workflows) and the factory gate is the same command, so lifecycle binding gives one source of truth with no CI change. B lets the factory gate pass while CI fails. C adds CI YAML for log readability only. The fast loop (`mvn test`) does not reach verify, but checkstyle on validate runs there; use -Dcheckstyle.skip in fast if needed. Windows `package` runs checkstyle only (cheap).
## What would change my mind
If the SpotBugs run is too slow or flaky for the factory gate.
## Implementation notes
Add the plugins in pom.xml with executions: checkstyle:check at validate, spotbugs:check at verify (before jacoco-check). Add -Dcheckstyle.skip=true to the `fast` command. Update docs/project/deployment.md § Build.
