- B is the best Node option because it reuses the existing `frontend/` npm@11 lockfile. But it needs a running stack, so it needs compose plus Q06 A (a fake in the src/main JAR, which minimal-implementation forbids) or Q06 B (a new fake-server container). C pairs with Q06 C and needs none of that.

CI turns that profile on with the SPA built (Q08 C, or a separate job running `mvn verify -Pe2e`). The browsers must be installed in CI with the Playwright CLI (`com.microsoft.playwright.CLI install --with-deps chromium`).
- D does not meet "Playwright E2E" in the plan and tech-stack.md. Reject it.
- No hard objections. A, B and C each break a sentence in the plan or in test-writing.md, and a one-line doc edit fixes each one.
