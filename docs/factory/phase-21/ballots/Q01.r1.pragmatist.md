  `<configLocation>config/checkstyle.xml</configLocation>`, `<consoleOutput>true</consoleOutput>`,
  `<failOnViolation>true</failOnViolation>`, `<violationSeverity>warning</violationSeverity>`,

  `RegexpSinglelineJava` / `MatchXpath` banning `@Autowired` on fields, and a `RegexpSinglelineJava` for
  `static final Logger (?!log\b)\w+` (message "Logger must be named log").
