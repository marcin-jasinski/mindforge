## Reasoning
- Question file: no HTML lib on classpath; one MIT dep with no transitive deps is the smallest robust answer.
- Registering text/html widens upload surface (scope change), so keep the converter private.
- Hand-written tag stripping on untrusted pages is a correctness and safety risk.
- Emit text only (no markup) so raw HTML never reaches a page body.
## What would change my mind
A rule against any new dependency, or a decision to accept HTML uploads.
