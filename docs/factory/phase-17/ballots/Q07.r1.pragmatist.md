## Reasoning
- A needs no migration: source_filename is VARCHAR(1000) and PageRenderer already shows it in citations, so the URL is provenance for free.
- Hash over extracted text is stable; the converter (D05) already yields the text, so no extra work.
- Reuse of IngestionService (lock, dedup, lesson rule, distinctTitle) matches D01, which routes articles through IngestionService.ingest.
- B adds a column, migration and DTO changes for no stated requirement (YAGNI); can be added later if needed.
- parent's uploader is the only user in context and uploaded_by is NOT NULL.
## What would change my mind
A requirement to query or display article URL separately from filename.
## Implementation notes
Fetcher builds a DocumentUpload-like input with metadata {"title": title}, filename fallback = last URL path segment (else host), sourceFilename = finalUrl truncated to 1000, mimeType text/html, uploadSource ARTICLE, uploadedBy = parent.uploadedBy; hash = ContentHash over extracted text bytes (UTF-8). Catch LessonAlreadyExistsException and LessonIdentityException, log and skip.
