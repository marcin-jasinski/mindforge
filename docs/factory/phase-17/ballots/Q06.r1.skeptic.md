## Reasoning
- Each URL becomes a run costing Extract + Write xN model calls; an uncapped count (C) lets one upload spend unbounded money. Bounded work is a stated constraint.
- Omission by count is acceptable only if counted: log "skipped K urls over cap" with fixed text (ai_agents.md "omission is counted"). The Phase 16 image rule (reject upload) cannot apply: D01 makes fetch async after commit, so there is no request to reject.
- Size cap must FAIL the fetch when hit, never truncate to a partial article (ai_agents.md "never truncate"). Also check Content-Length early, but enforce on bytes actually read (header can lie or be absent/chunked).
- HTML only: B feeds remote bytes to pdfbox/poi, a parser attack surface, and ParserRegistry/UploadSanitizer admit by MIME, so reuse invites Q05 coupling. Reversible later.
- Skip CODE blocks: URLs there are samples. Strip fragment; also strip nothing else (query may be identity).
- Hold a per-document wall-clock deadline (e.g. 60s) because 10 x 15s = 150s sequential occupies a virtual thread; sequential, no parallel fan-out. Each redirect hop counts toward the per-URL 15s total and max hops (e.g. 3), re-checked by EgressPolicy (D03).
- Content-type check on response header, case-insensitive, parameters ignored; missing type = reject.
- Testability: all limits in AppProperties so tests set tiny values; mock server tests for oversize, slow, wrong type.

## What would change my mind
Evidence that documents routinely cite more than 10 distinct articles and operators want more: then raise default, still capped.

## Implementation notes
- AppProperties.Articles record: maxUrlsPerDocument=10, maxBodyBytes=2_097_152, connectTimeout=5s, requestTimeout=15s, maxRedirects=3, documentDeadline=60s; documented in docs/project/deployment.md.
- ArticleFetcher/UrlExtractor: scan TEXT and HEADING blocks, regex for markdown links and bare http(s) URLs, trim trailing punctuation, drop fragment, LinkedHashSet for document order, limit N, log skipped count.
- Allowed types: text/html, application/xhtml+xml. Body read via bounded stream; exceeding cap throws a domain exception with fixed text.
