## Reasoning
- Plan 17.1 (implementation-plan.md:1524) names exactly three rejections: private ranges, `file://`, `data:`. A's
  scheme and port allowlists plus "public unicast" check meet all three with nothing extra.
- "Allowlists over blocklists" (docs/standards/global/validation.md:15) is met by A if the address rule is written as a
  positive predicate (`isPublicUnicast`), not as a list of bad ranges. Schemes and ports are a literal allowlist.
- A follows the existing pattern: `UploadSanitizer` (infrastructure/security/UploadSanitizer.java) holds a fixed
  allowlist (`allowedMimeTypes`) fed by `@Configuration`, with no operator-tunable narrowing.
- B adds a property, env var, suffix-match semantics (with IDN/case/trailing-dot edge cases) and a deployment.md entry
  that no requirement asks for. minimal-implementation.md: "No Speculative Abstractions", "Build What You Need".
- B is additive later: a host list can be added to `EgressPolicy` without changing A's contract, so choosing A now
  costs nothing in a year. Removing B later would break operator configs; so A is the more reversible start.
- C: articles come from arbitrary hosts; T28 #1 already chose the single global switch (ProcessingSettings). Two
  switches that must both be set is a confusing operator model and silently disables the feature.
- The trust model (architecture.md:276-277) already bounds damage from any host: create-only, no Supersede.
  A host allowlist would not add a needed control for the article threat; the SSRF threat is the address rule.

## What would change my mind
An explicit requirement (plan, ADR or ticket) for operator-narrowed egress, or Q03 deciding that the model provider
and OTLP endpoints also go through `EgressPolicy` with a configured host list (then B's list becomes needed).

## Implementation notes
- `dev.mindforge.infrastructure.security.EgressPolicy` (class, no interface unless Q09 needs a domain port).
  `URI check(String url)` returns the normalised URI or throws a domain exception (e.g. `EgressRejectedException`
  extending a meaningful base), with fixed messages, never raw remote text.
- Constants: `ALLOWED_SCHEMES = Set.of("http", "https")`; `ALLOWED_PORTS = Set.of(80, 443)` (port -1 maps to the
  scheme default). Reject userinfo in the URI.
- `static boolean isPublicUnicast(InetAddress a)`: false for anyLocal, loopback, linkLocal (incl. 169.254.169.254),
  siteLocal, multicast, CGNAT 100.64/10, IPv6 ULA fc00::/7, IPv4-mapped/compatible forms (unwrap and recheck).
  Check every resolved address; DNS rebinding and redirect handling belong to Q04.
- No `AppProperties` egress section; the only new property is the article switch decided by Q10.
- Tests: `EgressPolicyTest` table-driven (`@ParameterizedTest`) over each rejected class and accepted public address.
