## Reasoning
- D01 (ADR 0024) says an application service extracts URLs, fetches with no transaction, then queues via IngestionService.ingest. That is A's shape; B contradicts it.
- Matches the UploadPolicy (domain port) <- UploadSanitizer (infrastructure.security) and DocumentParser <- ParserRegistry patterns.
- Application may not import HTTP/jsoup; D04/D05 put HttpClient5 and jsoup private to the infrastructure adapter, so a port is needed for the application service to call.
- C adds a domain concept for logic only one application class uses; D06 limits/normalisation can be a pure package-private static method in the application class and stays unit-testable without HTTP. Move to domain only if a second caller appears.
## What would change my mind
Evidence that URL extraction has a second consumer (then C).
