- id: C1
  severity: nit

  location: src/main/java/dev/mindforge/infrastructure/web/HtmlArticleConverter.java:48
  claim: The whitespace pattern collapses only ASCII whitespace and U+00A0, so a paragraph that holds only another non-breaking space (U+202F narrow no-break space, U+2007 figure space) still gives a TEXT block.
  evidence: `<p>&#8239;</p>` -> TextNode " "; `[\s ]+` does not match it, and `String.strip()` keeps it because `Character.isWhitespace` is false for non-breaking spaces -> `add` sees non-empty content and emits TEXT " ". AC4 says whitespace-only elements give no block. Rare in real pages.
  fix: Use `Pattern.compile("[\\s\\p{Zs}]+")` (or add `  `) so all space separators collapse and strip.
