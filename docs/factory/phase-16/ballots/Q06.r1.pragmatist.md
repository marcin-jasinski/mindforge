## Reasoning
- Language: ai_agents.md requires writing in the source language; only preceding text gives that. Title alone is weak.
- Drop is cheap: IngestPipeline already counts omissions via `RunFailure.dropped(step, n)` (IngestPipeline.java:379, :462); reuse it with step "describe". No new counter or schema.
- JSON read via `ModelJson.read(getClass().getSimpleName(), ...)` as in QuizGenerator/SupersessionDetector; bad shape throws ModelOutputException.
- Marker is code-added, so the model cannot omit it; keeps provenance for ClaimExtractor `[position] text`.
- D01 says a blank/failed description is loud or a counted omission, never silent: relevant=false is a counted drop; relevant=true with blank description is a failure.
- Keep it small: context = title + up to N (e.g. 2) preceding TEXT blocks, capped by chars (e.g. 1500). Description capped (e.g. 600 chars; over-length is truncated or fails, pick fail for consistency).
