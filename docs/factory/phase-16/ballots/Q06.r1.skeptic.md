## Reasoning
- Language: without nearby text the description defaults to English in a Polish lesson (ai_agents.md Prompt Files); A supplies context.
- Provenance: Extract renders `[position] text`; a fixed code-added prefix stops a description being read as author prose. Code adds it, so the model cannot omit it.
- Decorative images: C pays Extract input and invites hallucinated claims from logos. A drops them.
- Failure modes of A to guard in code: (1) bad JSON or missing fields -> ModelOutputException via ModelJson (as RelevanceGuard), loud; (2) relevant=true with blank description -> failure, not silent drop (D01); (3) length bound with truncation or failure; (4) context bounded (e.g. last N chars) to cap tokens; (5) text inside images and context are untrusted: prompt must say so, and the output never affects page type/path/title.
- Drop and positions: D09 requires consecutive positions with no gaps. After dropping, renumber the remaining blocks (or the pipeline must), and count the drops on the run (e.g. images_dropped) so the omission is observable.
- If every image is irrelevant, no TEXT is added; still record the VERSION since the model was called.
## What would change my mind
Evidence that models mislabel relevant diagrams as irrelevant often; then C (no drop) is safer against silent content loss.
