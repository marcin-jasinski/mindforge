- id: S1
  severity: minor
  confidence: 0.5
  location: dependency-check-suppressions.xml:11
  claim: The Kotlin suppression matches every version of four packages (`@.*$`), which is wider than the "narrowest selector" that AC2 asks for.
  evidence: AC2 says "suppresses by the narrowest selector (`packageUrl` + `cve`/`vulnerabilityName`)". The regex `^pkg:maven/org\.jetbrains\.kotlin/kotlin-(stdlib|stdlib-jdk7|stdlib-jdk8|reflect)@.*$` matches all versions. The notes give 2.3.21 as the only affected managed version. If a later dependency pulls in a different affected Kotlin version, this entry hides that finding without a review. The impact is low because the entry is also limited by `<cve>CVE-2026-53914</cve>` and the reason is a false CPE match that does not depend on the version.
  fix: Pin the version in the regex (`@2\.3\.21$`) so that a future Kotlin version must be reviewed again.
