## Reasoning
- C contradicts accepted ADR 0008; blocker for the human, not a judge call.
- A ships a credentialed rule admitting any page on localhost:4200 in production by default (question Context, last bullet). Unsafe default.
- B meets ADR 0008 (origin list is an env var) and web-security.md (env var, never hardcoded, never *). Unset means no origin admitted, same as today's behaviour. Dev uses the proxy, so no default is needed.
- Test: with the var unset, a preflight from any origin gets no Access-Control-Allow-Origin; with it set, only that origin gets it, with credentials.
## What would change my mind
Evidence the dev workflow needs direct cross-origin calls to localhost:4200 (then A in dev profile only).
