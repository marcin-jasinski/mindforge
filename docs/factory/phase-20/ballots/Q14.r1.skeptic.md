## Reasoning
- B leaves an inconsistency the answered Q10 forbids: "a foreign id under one's own knowledge base -> 404". Report already
  does this (`RunReportService.java:47` `orElseThrow(() -> new NotFoundException("Run"))`); revert would be the one
  tenant-scoped id route that answers otherwise. Plan task 20.1 says "Fix any gaps found". Relaxing a security AC to fit
  the code is how such gaps become permanent; B also makes "unknown id" and "valid id, wrong state" indistinguishable to clients.
- A as worded breaks a deliberate invariant: `RevertServiceTest.shouldRefuseWhileAnotherRunHoldsTheLease` asserts
  `verify(runs, never()).findById(any(), any())` when the lease is busy - reads happen under the lease. Moving the read
  before `start()` would force editing that test and reorder lease-vs-read semantics for no gain.
- A2 keeps the order: `start()` (enqueue + claim) then `runs.findById(kbId, runId)`; empty -> `NotFoundException`, which
  extends `IllegalArgumentException` (`domain/model/NotFoundException.java:4`), so `TransactionOperations.execute` rolls
  back the queued REVERT row exactly as the 409 path does today (`RevertAndLeaseTest.aRevertRunIsNotRevertibleAndTheRefusalLeavesNoRun`
  proves no run is left). `GlobalExceptionHandler.notFound` already maps it to 404 `NOT_FOUND`.
- No existence oracle: the port is kb-scoped, so a foreign id and a random id both give 404; body detail is "Run" only (less than today's echo).
- Failure mode accepted: a busy KB answers 409 busy even for an unknown id (lease first). Harmless - no foreign data, and same as today.
- Blast radius: frontend maps only `REVERT_NOT_ALLOWED` (`frontend/src/app/shared/labels.ts:29`); revert is only offered for
  listed runs, so the UI never sends unknown ids. No existing test asserts 409 for an unknown run id.
- C is controller business logic and duplicates the service's read.

## What would change my mind
Evidence that a client or test relies on 409 for an unknown run id, or that the ticket's "test-only" scope is a hard rule that forbids any production fix in P20-06.
