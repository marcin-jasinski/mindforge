## Options merged
A and A2 are the same in substance: both make `RevertService.revert` throw `NotFoundException("Run")` when
`runs.findById(kbId, runId)` is empty and keep 409 for an existing non-revertible run. A2 only places the read after
`start()` (inside the same transaction) instead of before it. The evidence supports A2's placement: the unit test
`RevertServiceTest.shouldRefuseWhileAnotherRunHoldsTheLease` asserts `verify(runs, never()).findById(any(), any())`
when the lease is busy, so a read before `start()` breaks an intended invariant. The merged option A adopts A2's placement.
The architect's placement ("before start(...)") is overridden; its vote counts for the merged option.
