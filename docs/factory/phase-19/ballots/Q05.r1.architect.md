## Reasoning
- Mirrors Discord `/quiz start` and `/quiz answer` (QuizCommand.java), so both bots call QuizService.next/answer the same way (plan 19.2/19.3).
- Needs only the slash-command path; B adds block_actions and view_submission handlers, a new concept beyond plan 19.2.
- C is ambiguous: an answer text such as "start" or an empty answer collides with the start command.
- Single-line limit of the composer is a UX cost, not a correctness bug; B can be added later without breaking A.
- All options reply ephemeral (ADR 0032).
