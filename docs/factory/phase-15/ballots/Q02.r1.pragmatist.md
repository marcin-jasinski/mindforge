## Reasoning
- The CLI must not expose an API (Q02 context). B still boots Security and the API in a batch process.
- A uses one property in application-cli.yml; it works with the required `--spring.profiles.active=cli` entry point.
- Prefer `@ConditionalOnWebApplication` on SecurityConfig, SpaConfig, RateLimitConfig, ApiDocsConfig, JwtFilter and GlobalExceptionHandler. This adds no `@Profile` concept, and it follows the web type automatically.
- Controllers are plain beans without a server; they should be harmless. If a context test shows a failure, add the same condition to them.
- Verify with one context-load test under profile cli.
