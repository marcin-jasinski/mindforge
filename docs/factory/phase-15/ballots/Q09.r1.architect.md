## Reasoning
- Plan 15.2 and checklist require the same `QuizService` for answers; `answer`/`next` are shared. `start` is a public QuizService entry (QuizService.java:84), so the answer path is identical.
- `begin`/`isPreparing` exist so an HTTP request does not block; a terminal can block (blocking is fine, virtual threads, no reactive). Polling adds a loop and a timeout with no user gain.
- Scope options are not in plan 15.2; minimal-implementation forbids speculative extras, and moving package-private StudyScopes changes the API adapter. Add later if asked (reversible).
- Per answer print score and feedback only (Graded has no reference answer); summary at end; EOF ends quiz. Runner calls `requireOwner` with the `--user` user (D04).
