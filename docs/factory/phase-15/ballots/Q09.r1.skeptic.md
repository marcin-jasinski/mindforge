## Reasoning
- QuizService.java:84 `start` is the same generate() that `begin` runs in the background (l.94-108); `next` and `answer` are identical, so the "same answer path" rule holds.
- B adds failure modes for no benefit: the in-memory `preparing` map plus a virtual-thread executor (l.62), polling loop, timeout. A terminal user waits anyway. Errors in `start` throw NotFoundException directly; in B they surface late through `isPreparing().join()` (l.114-131).
- `start` returns a QuizSession holding referenceAnswer: the CLI must print only question, score, feedback. Add a test with a stub that asserts the reference answer and grounding text never appear in stdout.
- C: StudyScopes is package-private in api.controller; moving it is a refactor not required by plan 15.2. Add later if asked (reversible).
- No transaction wraps the model call in `start` (no @Transactional seen in the generate path); keep the CLI free of one.
- EOF on stdin: end quiz cleanly with a summary, non-zero exit not needed.
