- `AccountService.register` / `signInWithProvider` apply `unreserved` after `normalise` (trim + `toLowerCase(Locale.ROOT)`) and before any `findByEmail`/`insert`/`recordLogin`, so a refused email inserts nothing and records no login. - Every string `syntheticEmail` can return ends with `@users.invalid` and is lowercase, so every bot email is covered by the refusal.
- `syntheticEmail` null/blank/non-alnum ids throw `IllegalArgumentException` (regex `matches` needs one or more chars); length bound is exact (test asserts 255 passes, 256 fails).
- `reservedEmail()` is `conflict = true`, mapped by `GlobalExceptionHandler.account` to 409 `EMAIL_TAKEN` with the fixed message only; no handler change needed.
- `OAuthLoginSuccessHandler` is unchanged per the ticket's recorded decision; the exception propagates to the default error path.
