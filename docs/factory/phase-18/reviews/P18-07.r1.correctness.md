- id: C1
  severity: minor
  confidence: 0.5
  location: src/main/java/dev/mindforge/discord/QuizCommand.java:117
  claim: A `NotFoundException` from the follow-up `next(...)` call after a successful `answer(...)` is caught by the same catch as the grading call, so a graded and recorded answer is reported as "No active quiz. Run /quiz start." and its score and feedback are lost.
  evidence: `answer` runs `quizService.answer(...)` (records the score and advances the cursor via `sessions.updateCursor`) and then `nextOrFinished(...)` -> `quizService.next(...)` -> `owned(...)` -> `sessions.find(kbId, sessionId, Instant.now())`, all inside the `try` whose `catch (NotFoundException | NotOwnerException | QuizFinishedException e)` sends only NO_ACTIVE_QUIZ. If the session's `expiresAt` (start + TTL) passes between the two calls, `find` returns empty, `next` throws `NotFoundException`, and the user sees no score although `study.recordQuizScore` already ran. The window is small (only at the TTL boundary), hence minor.
  fix: Build the score/feedback text before the `try` around `next`, or call `next` outside the catch and on `NotFoundException` there clear the entry and append FINISHED/NO_ACTIVE_QUIZ after the score and feedback.
