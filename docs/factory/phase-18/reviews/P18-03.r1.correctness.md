  location: src/main/java/dev/mindforge/application/service/ExternalIdentityService.java:68
  claim: The 255-char cut runs after `TextRules.singleLine`, so the stored display name can end in a space, which breaks the trimmed single-line form that `singleLine` produces.
  evidence: displayName = "x".repeat(254) + " yz" -> singleLine keeps it as is (length 257) -> substring(0, 255) = 254 x's + " " -> the stored name ends with a trailing space. singleLine's contract is "... trimmed".
  fix: Strip trailing whitespace after the cut, e.g. `return name.substring(0, end).stripTrailing();` (the result cannot become empty because the first char is not whitespace).
