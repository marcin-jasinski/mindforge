## Reasoning
KBs are private single-owner (question constraints). Answers are cut from the owner's wiki, so public posting leaks content to every channel member. A is one flag on every reply, no new option or branching. C adds an option on every command, a public path to test, and a leak path; it can be added later without breaking A, so A is the reversible start. Ephemeral loses channel history, which is acceptable for a private tool.
