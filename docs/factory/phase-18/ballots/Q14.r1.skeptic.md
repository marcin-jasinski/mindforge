## Reasoning
- KBs are private, single-owner (Q14 constraints). Public answers expose wiki content and the user's questions to every channel member; this is data leakage, and cannot be recalled once posted (Discord keeps history, may be logged by other bots).
- Errors and upload results can carry document titles or paths; ephemeral is the safe default for them too.
- Quiz grades are study data; must stay private.
- C needs one more option per command, tests for both modes, and one mistaken flag leaks. Can be added later without schema change, so A loses little.
- Ephemeral loss of history is acceptable: the web UI keeps the Query interaction (D06).
## What would change my mind
A stated requirement for shared channel learning, with an explicit per-use opt-in.
## Implementation notes
Every reply path in the Discord handlers sets ephemeral (flags EPHEMERAL / setEphemeral(true)) including deferred replies and error replies. Test: every handler response is ephemeral. Do not include reference answers or grounding excerpts.
