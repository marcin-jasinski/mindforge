## Reasoning
- Constraints: no new port without a caller; an in-adapter map is in-process only (scope.md line 59-60 lists the Query API).
- A needs no state, no eviction, no restart loss, no "new" option. The requirement (answer a question with cited paths, W06) is fully met.
- Cost of A: no follow-up context and many one-turn interactions in web history. Acceptable for a first bridge; B can be added later without a schema change.
- B adds a map, timeout config, a `new` option, and behaviour that differs after restart.
